- 所有 ref.bib 文献均为英文，使用英文 biblatex 字符串完全合理
- 保留 `\PassOptionsToPackage{final}{hyperref}` + `\hypersetup{final}` 解决 hyperref draft
- 保留 `\usepackage{csquotes}` 满足 biblatex 推荐
- 剩余约为字体 shape 和 overfull box（内容级，非 preamble 问题）

## 引用方括号最终修复
- 之前的 `\renewcommand*{\mkbibparens}[1]{\mkbibbrackets{#1}}` 只让年份带括号，不是整体方括号引用
- 最终方案：`\renewcommand*{\mkbibparens}[1]{#1}`（去掉年份内括号）
  + `\DeclareCiteCommand{\cite}[\mkbibbrackets]{...}`（外层包方括号）
- 效果：`[Gelfand 1941]`、`[Naimark 1964]`、多引用 `[Author1 Year1; Author2 Year2]`
