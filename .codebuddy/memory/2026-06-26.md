## [SKILL] 微信公众号公式 PNG 渲染 v2 — 修复单字符裁剪

**问题**：v1 脚本中 35/145 个单字符公式（如 `z`, `p`, `I`）被裁剪为 6-12px 宽的极小图片，微信编辑器中几乎不可见。

**根因**：Playwright `boundingBox()` 返回 MathJax `mjx-container` 的布局宽度极小（单字符 6-10px），`screenshot()` 按此尺寸截图导致 SVG 裁剪。

**修复 (render-png-v2.cjs)**：
- 每个公式外包 `<div>` 加 `padding:2px 8px; min-width:30px`
- 对包裹 div 截图而非 `mjx-container`
- `page.setViewportSize({ width: 1920, height: 1080 })` 防止视口裁剪
- 最终宽度取 `max(boundingBox.width, 30)`

**结果**：v2 版本 0 个极小图片，145 个公式全部正常，293KB。
