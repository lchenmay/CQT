# 公众号写作方案

## 一、定位与风格

**公众号名**：西窗烛（待确认）

**一句话定位**：用范畴论的视角，讲人人都能懂的数学故事。

**读者画像**：对数学有好奇心的泛科技人群——程序员、工程师、理科大学生、科普爱好者。不需要数学专业背景，但愿意动脑。

**风格约定**：
- 每篇 2000-4000 字，独立成篇，读完即走
- 核心观点用自然语言讲清楚，公式只是佐证，不超过 5 个
- 每篇有一个「为什么」作为钩子——为什么人类需要复数？为什么拓扑学会诞生？
- 文章之间用**主题标签**和**文末「相关阅读」**建立网状关联，不做线性编号

## 三、非线性的标题体系

### 设计原则

- **绝不编号**：没有"第一讲"、"Part 1"、"（上）（中）（下）"，每篇标题即独立入口
- **标题即钩子**：读者不需要知道任何前置文章，标题本身就是一个让人想点开的问题或意象
- **六星群 + 漂浮卫星**：6 个主题星群，外加跨主题的漂浮文章，读者在不同星群之间跳跃
- **星群内部关联，星群之间互引**：同星群文章共享一个「星群名」标签，文末相关阅读可以跨星群

### 标题命名风格

混合使用四种风格，避免单调：
- **问题型**：为什么……？什么东西……？——直接勾起好奇
- **意象型**：用比喻命名——「咖啡杯变成甜甜圈」「从石头里长出几何」
- **悖论型**：看似矛盾的陈述——「空间 = 代数」「逻辑也是几何」
- **故事型**：人物+事件——「康托尔被同行逼疯的那一年」「Grothendieck 的概型革命」

## 四、网状关联机制

### 不使用线性编号，用三种方式建立关联：

**1. 文末「相关阅读」**（每篇 2-3 篇）：
```
---
相关阅读：
- 《箭头比对象更重要——范畴论的第一课》（如果你还没看过这篇，建议先读）
- 《空间 = 函数代数：Gelfand 对偶的惊人洞见》（本文的自然延伸）
```

**2. 标签系统**（每篇文章打 2-3 个标签）：
文章开头标注标签，读者点击标签可以看同主题所有文章。标签列表：`范畴` `集合` `关系` `张量` `拓扑` `流形` `代数` `谱` `概率` `辛几何` `Gelfand` `Topos` `量子` `层` `概型` `同调` `复数` `AI`

**3. 系列导航页**（菜单/自动回复中的固定文章）：
一篇置顶的「从这里开始」导航文章，用上面那张网状图做视觉引导，标注每篇文章的阅读梯度。

## 六、文章模板

每篇文章的结构——**不标序号，不写「第X篇」**：

```
【星群】复数  |  【梯度】◎

【钩子】（1-2 段，一个具体的、让人好奇的问题或故事）

【正文】
- 概念直觉（不用公式，用比喻、故事、图表）
- 逐步深入（引入少量公式，每个公式都有自然语言解释）
- 范畴论视角（用一两段话展示「范畴论怎么看这个问题」——这是 CQT 的独特卖点）

【桥接】（一段话连接到更大的数学图景，暗示可以从这里跳往哪个星群）

---
🜚 相关阅读：
- 《箭头比对象更重要》——如果你还没看过这篇，它解释了本文用到的一个关键视角
- 《空间 = 函数代数》——本文的自然延伸，Gelfand 对偶的完整故事
```

### 标题格式约定

- 主标题不超过 20 字
- 不使用冒号分隔副标题（那是知乎专栏的风格，公众号用短标题 + 封面图传达氛围）
- 封面图用抽象几何 / 数学艺术风格，不堆文字
- 摘要（公众号的 64 字摘要）单独写一句钩子，不和标题重复
